# 🎮 C# & Game Development Architecture Practice

Welcome to my C# practice modules! This directory contains object-oriented scripts, game state logic, inventory mechanics, and console-based simulation systems designed to build a strong foundation for **Unity / Unreal Engine** game development.

---

### 📁 Code Structure & Modules
* **`player.cs`** 🛡️: Demonstrates **OOPs Encapsulation**, private field protection, and custom Getter/Setter logic for player health state.
* **`itemshop.cs`** 🛒: Implements in-game economy logic, condition verification, item purchase algorithms, and input parsing.
* **`Program.cs`** 🚀: Core execution entry point combining classes, data structures, and game flow controller.

---

### 🧠 Core Concepts Mastered
- **Encapsulation & Access Modifiers:** `private`, `public` data protection.
- **Game Mechanics Logic:** Deducting currency, conditional buying, user interaction flow.
- **Value vs Reference Types:** Data assignment & memory copy logic.

> 🎯 *Aim: To write clean, modular, and performant C# architecture before scaling up to Unity Monobehaviours.*
