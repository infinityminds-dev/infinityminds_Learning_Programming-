# ☕ Java Core Practice & OOPs Logic

This directory contains clean, structured Java programs covering core language fundamentals, Object-Oriented Programming (OOPs) concepts, array data structures, and exception handling logic.

---

## 📌 Topics & Files Included

| File Name | Key Concepts Covered |
| :--- | :--- |
| **`JavaBasics.java`** | Variables, Data Types, If-Else Conditionals, For Loops |
| **`StudentOOPs.java`** | OOPs Encapsulation, Classes, Objects, Getters & Setters |
| **`ArrayOperations.java`** | Array Manipulation, Max Element Search, Average Calculation |
| **`StringAndExceptions.java`** | String Utility Methods, Try-Catch Block, Exception Handling |

---

## 🛠️ Key Takeaways
- **OOPs Fundamentals:** Strong focus on data hiding (Encapsulation) and class design.
- **Robustness:** Error handling using `try-catch-finally` blocks.
- **Logic Building:** Practice with array iteration and string manipulation.
