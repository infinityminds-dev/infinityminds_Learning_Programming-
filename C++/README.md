# ⚡ C++ Core Concepts, Logic & OOPs Vault

Welcome to the **C++ Programming Directory**! This space contains practical code implementations, logic-building exercises, and core algorithms based on the complete 72-video C++ mastery course by Code With Harry.

---

## 📌 Syllabus & Topics Covered

### 🟢 Phase 1: Basics & Fundamentals (Videos 1–15)
* **Introduction & Setup:** Environment setup, compiler basics (GCC/G++), and first `Hello World` program.
* **Core Syntax:** Variables, Data Types, Input/Output (`cin`/`cout`), and Comments.
* **Operators & Header Files:** Arithmetic, Logical, Relational, Bitwise operators, and system header files.
* **Control Flow:** `if-else` conditionals, `switch-case` statements, and control structures.
* **Loops:** `for`, `while`, and `do-while` loops with `break` & `continue` logic.

### 🟡 Phase 2: Memory, Functions & Pointers (Videos 16–25)
* **Pointers & Memory Addresses:** Pointer basics, dereferencing, pointer arithmetic, and null pointers.
* **Arrays & Pointers:** 1D/2D Arrays, array manipulation, and dynamic memory association with pointers.
* **Functions & Prototyping:** Function declaration, call-by-value vs. call-by-reference.
* **Advanced Function Concepts:** Inline functions, default arguments, constant arguments, and recursion/recursive series.

### 🟠 Phase 3: Object-Oriented Programming (OOPs) (Videos 26–58)
* **Classes & Objects:** Public/Private access modifiers, member functions, and nested member functions.
* **Memory Allocation:** Static data members & static methods in classes.
* **Arrays of Objects:** Passing objects as function arguments & returning objects.
* **Friend Functions & Classes:** Encapsulation exceptions, friend functions, and friend classes.
* **Constructors & Destructors:** Default, parameterized, copy constructors, constructor overloading, and destructor lifecycle.
* **Inheritance:**
  * Single, Multiple, Multilevel, Hierarchical, and Hybrid Inheritance.
  * Ambiguity Resolution & Virtual Base Classes.
  * Constructors in derived classes.
* **Pointers to Objects:** `this` pointer, polymorphism, compile-time vs. run-time polymorphism.
* **Virtual Functions & Abstract Classes:** Pure virtual functions and abstract base classes.

### 🔴 Phase 4: File I/O, Templates & STL (Videos 59–72)
* **File I/O:** Reading/writing files using `fstream`, `ifstream`, and `ofstream`.
* **Templates & Generics:** Function templates, class templates, and multiple parameter templates.
* **Standard Template Library (STL):**
  * **Containers:** Vector, List, Deque, Map, Set.
  * **Iterators & Algorithms:** Traversing containers and using built-in sorting/searching algorithms.
